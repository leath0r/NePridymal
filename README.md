# NePridymal — Telegram Mini App казино на подарках

Полностью рабочая игра: сервер (FastAPI + SQLite) и фронтенд (Telegram Mini App) в одной папке.
Нужен только токен бота.

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather) (`/newbot`) и скопируй токен.
2. Скачай репозиторий (`git clone …` или Code → Download ZIP) и распакуй.
3. Запусти:
   - **Windows** — двойной клик по `start.bat`
   - **Linux / macOS** — `./start.sh`
4. Вставь токен, когда спросит. По желанию — свой Telegram ID (узнать у [@userinfobot](https://t.me/userinfobot)), чтобы получить админ-панель.
5. Открой своего бота в Telegram → кнопка **«Играть»**.

Первый запуск сам ставит Python-зависимости и скачивает `cloudflared` — бесплатный HTTPS-туннель
(Telegram открывает игры только по https). Пока окно открыто — игра работает. Остановить — `Ctrl+C`.

Нужен Python 3.11+. На Windows `start.bat` поставит его сам через winget, если его нет.

## Настройки — `settings.toml`

Шансы, возврат игрокам, стартовые звёзды, бонусы, призы, курс звёзд, кэшбэк и т. д.
Меняешь число → сохраняешь → перезапускаешь игру. Каждая строка подписана.

## Где что лежит

| Путь | Что это |
|---|---|
| `start.bat`, `start.sh` | запуск одной кнопкой |
| `run.py` | спрашивает токен, поднимает туннель, собирает фронт, запускает сервер |
| `settings.toml` | шансы и экономика |
| `.env` | токен бота и ID админов (создаётся при первом запуске, **не выкладывать**) |
| `data/game.db` | база игроков (создаётся сама; бэкапь этот файл) |
| `server/` | сервер: игры, экономика, бот |
| `web/` | фронтенд (исходники; `build.py` склеивает их в `bundle.js`/`bundle.css`) |

## Свой домен вместо туннеля

Адрес туннеля меняется при каждом перезапуске (кнопка «Играть» обновляется сама).
Для постоянного адреса: поставь перед сервером nginx/Caddy с HTTPS, проксируй на `127.0.0.1:8795`
и впиши в `.env` строку `PUBLIC_URL=https://твой-домен`.

## Перенос игроков

Скопируй `data/game.db` (при остановленной игре) — вся история, балансы и подарки переедут вместе с ним.
